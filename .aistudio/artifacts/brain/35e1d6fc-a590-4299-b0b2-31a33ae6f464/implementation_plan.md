# 四半世紀 · 全屏 2D 地图主界面与星露谷式地图交互升级方案

将游戏主界面升级为 100% 铺满全屏的无遮挡 2D 地图画布，去除顶部横条栏目与屏幕方向文字键，改为左上角与右上角独立圆角粗描边贴纸按钮；完整实现大地图镜头平滑跟随平移、走到建筑门口自动推门进入室内小地图、跨板块抵达港口与机场、餐厅固定方桌 4 格隐形摆菜，以及将音乐与工坊模块统一整合至右上角设置与手机面板。

## 用户确认事项与关键决策

> [!IMPORTANT]
> 以下关键交互方案已根据您的确认锁定，百分之百保留现有立绘工坊、小人工坊、建图工坊、人设、世界书、关系、记忆、手机、论坛、美化与全部 API 存档数据，绝不删减任何已有功能。

- **启动主画面与入口排布**：打开软件直接进入 100% 铺满全屏的 2D 地图主画面。左上角边缘仅放置独立的「地图」按钮与「状态」贴纸角标；右上角边缘依次放置独立的「手机」「论坛」「设置」三个圆角粗描边贴纸按钮；现有的立绘工坊、建图工坊、人设、世界书、关系、记忆、美化模块整齐收纳在「设置」与「手机」面板的快捷入口中，点开即弹出对应独立窗口，关闭即回到纯净大地图。
- **大地图与室内小地图进出方式**：在大地图上控制 Q 版小人走到餐厅、Kilig 酒吧、第十三眼宠物店、审判庭、静默回廊、薄荷匣、天堂之门酒吧、OC 房间或驻地的大门口触发区时，自动推门平滑切换到该建筑的室内小地图；在室内小地图走到门口出口处时，自动返回大地图对应建筑门口。
- **场景互动按钮触发方式**：彻底移除原地图顶部的整条栏目框与音乐播放按钮；当小人处于餐厅或酒吧桌边时自动浮现「点菜」贴纸按钮，靠近在场角色或在底部对话栏内提供「打听」「文游」按钮，保持地图视野干净通透。

## 1. 核心概念与界面布局

- **全屏无遮挡 2D 地图底座**：底层为 100% 视口宽高的 2D 游戏地图容器，彻底取消顶部横条导航栏、方向键文字按钮与主界面音乐按钮。
- **四角独立贴纸按钮**：
  - **左上角边缘**：独立「地图」按钮，以及极简「状态」小贴纸角标，点击展开查看饱腹度、金币、功德、银币详情。
  - **右上角边缘**：独立「手机」按钮、「论坛」按钮、「设置」按钮，均采用现有 CSS 变量与 `.moe-btn` 圆角粗描边贴纸造型。
  - **屏幕底部边缘**：默认收起为极细条的「对话」入口，点击展开现场实时延迟对话栏，再次点击收起，绝不遮挡地图画面。
- **音乐与全模块统一收进设置**：
  - 主画面不展示任何音乐按钮；在「设置」面板内新增独立的「音乐」子页，集中管理全局音乐开关、音量滑块、当前播放状态以及为各个板块与室内地图绑定专属音乐直链 URL，切换地图时后台自动无缝切换对应背景音乐。
  - 在「设置」面板顶部提供「立绘」「建图」「人设」「世界书」「关系」「记忆」「美化」「桌面」快捷模块入口，一键直达所有已有工作台。

## 2. 视觉设计与交互体验

- **视觉风格与 CSS 规范**：
  - 严格复用 `style.css` 现有的 `--text-primary`、`--text-secondary`、`--accent-color`、`--background-color`、`--card-bg`、`--border-color`、`--secondary-bg`、`--tukey-*` 变量体系以及 `.moe-btn`、`.moe-input`、`.moe-card`、`.setting-item`、`.modal`、`.modal-content` 类名，不硬编码任何颜色，不使用任何 emoji，所有图标均使用干净的 SVG 矢量线条图标。
  - 严格遵守表单与下拉框防裁切规范：`select` 保持充足高度与标准行高，复选框与单选框固定尺寸禁止拉伸，列表条目使用弹性行排布。
- **核心交互流程**：
  1. **大地图走动与镜头平滑跟随**：每个板块设有比屏幕更大的区域大地图画布，玩家通过点击地面任意位置或按住屏幕拖动隐形摇杆控制当前主控 Q 版小人四向走动，镜头视口随小人位置平滑计算偏移量，始终将小人保持在视野中心并限制在地图边界内。
  2. **大地图建筑门口自动进出室内**：区域大地图上分布该板块各建筑外观与门口热区，小人走到门口热区自动进入对应室内小地图；室内小地图底部设有出口热区，走到出口自动返回区域大地图建筑门前。
  3. **左上角「地图」跨板块港航与同板块快传**：
     - 跨板块出行：点击其他板块卡片时，根据板块地理属性自动搭乘对应交通工具抵达该板块的交通枢纽大地图，如阿尔塔空港、永无乡云津渡口、既白东海海港码头、三途川忘川渡口、安特拉妖精驿站、耶罗德圣城空港、诺比特南境驿站，并支持新增自定义板块。
     - 同板块直达：点击当前板块下的任意店铺或建筑卡片，小人直接快速传送至该建筑门口或室内。
  4. **餐厅小地图方桌入座与 2×2 隐形四格摆菜**：在带餐桌的室内小地图中，小人走到方桌旁可入座左席或邀同伴入座右席，利用图层深度与坐姿自然端坐桌前；点击桌边浮现的「点菜」贴纸按钮选择或上传生成菜品，菜品自动去白底并摆入桌面正中央 2×2 四个隐形格子中。

## 3. 关键架构决策

- **决策一：双层地图结构设计**
  - *方案*：为每个大陆板块构建「区域大地图」与「室内小地图」两级结构。区域大地图采用 2000×1400 大画布并承载各店铺建筑入口与港口机场坐标；室内小地图承载具体房间背景、固定方桌、2×2 摆菜格与自定义家具。
  - *原因*：既能实现《星露谷物语》式大地图平滑卷轴探索与走到门口进店的真实空间感，又能100%兼容现有的室内地图背景上传、AI 生地图、家具摆放与餐厅方桌点菜逻辑。
- **决策二：保持单文件与本地数据库增量演进**
  - *方案*：保持现有 `index.html` 与 `style.css` 文件结构及 Dexie IndexedDB 数据库表结构不变，所有返回地图逻辑统一收敛到全屏地图主界面。
  - *原因*：确保已有立绘二十一态差分、四向行走小人、身高对比舞台、API 预设等全部功能零损坏、零丢失。

- **数据存储与状态同步**：
  - `db.maps`：存储各区域大地图与各室内小地图的自定义背景图、专属音乐直链 URL。
  - `db.characters`：存储角色的全身立绘、二十一态差分、四向 Q 版行走图、真实身高，主控小人直接在全屏大地图与室内地图中实时渲染走动。
  - `db.foods` 与 `db.furnitures`：存储自定义上传或 NovelAI 生成的透明底菜品与家具，直接作用于餐厅方桌 2×2 隐形格与地图画布。
