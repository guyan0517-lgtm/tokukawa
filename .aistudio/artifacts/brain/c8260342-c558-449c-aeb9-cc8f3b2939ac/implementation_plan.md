# 物品栏功能实施方案

## 一、界面与交互设计

1. 底部工具栏按钮调整
   - 将物品栏背包按钮移动至时间轴按钮之后，作为工具栏最后一个功能按钮。
   - 点击物品栏按钮展开右侧精致竖条栏，再次点击立即收起，无暗色背景遮罩，不遮挡主聊天区域。

2. 物品栏竖条主体结构
   - 顶部操作区：分类切换标签 全部、线索、道具、武器，右上角添加按钮。
   - 列表主体：每一项采用弹性排版，左侧圆形头像与占位图标，中间两行显示名称、分类标和简介，右侧配置置顶五角星和操作按钮。
   - 底部管理栏：底部配置管理按钮，点击切换至批量勾选删除与编辑模式。

3. 详情面板与表单设计
   - 独立居中悬浮卡片，展示大尺寸头像、名称、分类、数值与简介。
   - 添加与编辑表单支持名称、简介、分类选择、武器伤害加值与DB属性、线索HTML详细内容。
   - 头像区域支持点击预览与长按生图，按标准方图尺寸生成并裁切居中填充。

## 二、数据结构与存储设计

1. 物品核心字段
   - id：唯一标识符
   - name：物品名称
   - desc：简要简介与作用
   - category：线索、道具、武器
   - avatar：头像图片数据或链接
   - content：线索详细HTML全文，仅线索类型使用
   - damageBonus：伤害加值，仅武器类型使用
   - dbBonus：DB数值，仅武器类型使用
   - isPinned：是否星标置顶
   - source：来源类型
   - createdAt：创建时间戳

2. 本地持久化
   - 使用统一本地存储结构保存当前角色的物品栏列表，确保离线与刷新不丢失。

## 三、核心逻辑与联动实现

1. 道具使用与消息卡片
   - 道具行点击使用后，在聊天流中插入灰色居中系统提示语气泡，同时渲染物品使用卡片。
   - 物品保留在背包中，不自动扣减。

2. 线索阅读与气泡转化
   - 线索项提供阅读按钮，弹出纯净阅读层，安全渲染富文本HTML内容。
   - 消息气泡长按菜单中的引用项升级为转化线索选项，自动提取气泡内容生成线索物品。

3. AI记忆注入与提示词协同
   - 在构建对话提示词与系统上下文中，注入物品栏摘要信息，包含全部物品名称、简介及武器鉴定数值。
   - 线索详细HTML全文严格保留在本地，不注入AI上下文中，保护剧透并优化上下文长度。

4. AI赠送物品自动识别
   - 监听解析AI回复文本中的结构化物品字段，自动将剧情中获赠的物品入库并触发头像生成。

## 四、验证与交付步骤

1. 验证底部按钮位置与竖条栏展开收起无遮罩效果。
2. 验证全部、线索、道具、武器分类筛选与五角星置顶排序。
3. 验证线索阅读、气泡转化线索、道具卡片发送、武器数值录入。
4. 验证AI记忆注入与系统回复中解析新增物品的完整流程。
