# 剧本剧场大改版与高级文游演出系统方案

重构首页桌面为六个不重复软件并将「剧本」固定在最下方左下角，实现先选模组与章节再观看、章节播完自动连播下一章、单角色全套设定与立绘差分包导入导出、设置页自定义字体URL全局覆盖与无背景弹幕透明度调节，以及黑幕浮字转场、立绘插入与人物抖动等高级文游演出系统。

## 用户确认的核心决策

- **首页桌面去重与左下角剧本入口**：去掉桌面上重复的图标，只保留「模组、角色、立绘、音乐、美化、设置」六个不重复的核心软件，并将观看用的「剧本」固定放在桌面最下方的左下角。
- **模组管理与剧本选集连播分离**：
  - 点进「模组」软件：专门负责自己定大模组标题、分卷分章、查看与编辑模组里的每一章内容。
  - 点进左下角「剧本」软件：先进入「模组与章节选集大厅」，选好要看哪个大模组、哪一章后才进入剧场开始观看；当前章节播放完最后一句后，自动无缝跳入下一章继续播放。
- **单个人物全套立绘与信息包导入导出**：在角色档案界面增加两字按钮「导包」与「导出」，支持将单个角色的姓名、身高、音色、外貌语癖、基础全身立绘及全部二十五态表情动作差分图片打包成独立JSON文件一键导出与导入。
- **高级视觉小说剧场UI重构与极简角落矢量图标**：
  - 彻底重做剧场底部的对话框与说话人名字牌，采用半透明深邃磨砂渐变层、精致内描边与高对比度衬线名字牌，告别简陋方框。
  - 撤掉剧场顶部摆成一排的冗余按钮，仅在左上角与右上角保留极小巧的纯SVG矢量图标：左上角为「选集」与「退出」，右上角为「弹幕」开关与「自动」连播开关。
- **无背景纯文字弹幕与设置页自定义字体URL及透明度**：
  - 弹幕彻底去掉胶囊背景框与边框，改为纯文字加柔和文字投影飘屏。
  - 在外面的「设置」软件中增加「全局与剧场自定义字体URL」输入框与本地字体上传，填入字体URL后立即生成动态 `@font-face` 覆盖全局与剧场文字；同时在「设置」中增加「弹幕文字透明度」滑块。
- **高级文游自然演出效果**：
  - **全屏黑幕缓慢浮现文字转场**：遇到场地切换、时间推进或神秘深邃的关键信息时，画面渐入纯黑幕，屏幕正中央缓慢浮现白字，停留或点击后自然散去。
  - **立绘动态演出与镜头震动**：支持剧本中间自然插入立绘登场、人物受惊或激动时的立绘抖动、走近放大、开心轻跳、遭受袭击或理智检定失败时的画面震动与暗角呼吸灯效。
  - **逐字打字机台词浮现**：对话框文字支持自然逐字浮现，点击对话框若文字尚未打完则立即显示全句，再点一下进入下一句。

## 1. 整体流程与核心概念

- **核心定位**：将模组制作与剧本沉浸式观看彻底解耦，让创作者在「模组」与「立绘」中准备素材，在左下角「剧本」中获得真正商业级视觉小说的演出体验。
- **核心价值**：
  - **桌面清爽不重复**：每个软件各司其职，左下角一键直达剧本选集。
  - **单角色资产随时迁移**：画好的一整套人物立绘差分与设定可单独打包备份或跨工程导入。
  - **电影级文游演出**：黑屏浮字、立绘抖动、画面震动、逐字打字机与无背景透明弹幕自然衔接。

## 2. 用户体验与视觉设计

### 核心交互流程
1. **桌面与选集大厅**：打开应用看到去重后的清爽桌面，点击最下方左下角的「剧本」，进入选集大厅，上方可切换或重命名大模组标题，下方卡片列出该模组的所有章节与进度，点击任意一章即刻进入全屏剧场。
2. **剧场沉浸演出與自动连播**：
   - 遇到场景转换或深邃序言时，全屏黑幕渐显，中央逐字浮现白字。
   - 正常对话时，角色按真实身高比例立于舞台，说话人微亮放大，受惊时立绘左右急促微抖，亲近时平滑放大，战斗或发狂时画面震动并浮现深色暗角。
   - 当本章最后一句播放完毕，自动加载并无缝切入下一章的第一句。
3. **角色立绘包导入导出**：在「角色」档案页点击「导出」即可下载该角色包含全部差分图片的完整档案包，点击「导包」即可随时载入新角色。
4. **设置页字体URL与弹幕透明度**：在「设置」中填入字体文件URL，全站与剧场文字立即切换为该字体；拖动弹幕透明度滑块即可调节无背景弹幕的浓淡。

### 视觉与排版规范
- **剧场对话框与名字牌**：底部采用渐变暗幕衬底与细微高光描边，左侧上方悬浮精致斜切或衬线艺术感说话人名字牌，右侧以静默无框数字显示当前句进度。
- **角落极简矢量图标**：左上角与右上角仅放置 `28px × 28px` 半透明纯SVG矢量图标，无杂乱文字排布。
- **纯文字弹幕**：使用 `--text-primary` 与纯白高光文字配合柔和文字阴影，无背景色、无边框，透明度直接读取设置页的 `--danmaku-opacity` 变量。

### 演出指令与数据结构扩展
- **单行剧本演出字段 `effect`**：
  - `none`：常规对话或旁白
  - `blackout`：全屏黑幕中央缓慢浮现一行文字
  - `shake_char`：当前说话人物立绘急促抖动
  - `zoom_char`：当前说话人物立绘走近放大特写
  - `jump_char`：当前说话人物立绘轻快跳动
  - `shake_screen`：全屏画面剧烈震动加暗角呼吸
- **AI整理剧本自动编排演出**：在 `generateChapterScriptByIndex` 中，AI会自动将场景切换、时间推进或神秘高深信息标记为 `blackout` 黑幕浮字，并根据人物情绪自动附上 `shake_char`、`zoom_char`、`jump_char`、`shake_screen` 演出效果；用户在剧本编辑页也可通过每行的演出下拉框随时手动修改。
