# 跑团日志全篇AI分章、纯净人物档案柜与智能音乐台搜索Replay方案

本方案已完全按你的要求调整到位：**AI提取模组人物时只提取名字与分类归档，绝不瞎提取外貌、绝不擅自总结性格**，外貌与人设由你自己写或传图，100%复用原有的立绘写词与25态差分垫图系统；同时内置**JD音乐台、网易云音乐、QQ音乐自动搜索与歌名歌手权重排序播放系统**。

## 核心规则确认

> [!IMPORTANT]
> 以下是完全按你心意敲定的五条铁律，不需要你再操心任何技术细节：

1. **AI提取人物只建空档案，绝不瞎编外貌和性格，100%沿用你原有的立绘写词与垫图系统**：
   - 发整篇模组Log出去时，AI只负责把出场人物的**名字**和**身份分类** 主角PC、配角NPC、旁白KP 提取到分类档案柜里。
   - **角色的外貌和性格完全由你自己写**！点角色旁的 **立绘** 按钮，直接进入你原本做好的立绘工坊：你可以自己写外貌词、自己上传参考图片让AI写提示词、用底图垫图生成25态表情动作差分；在生成剧情CG时也支持直接选角色立绘或自己上传图片做垫图。
2. **整篇Log先由AI判断位置插分隔符分章，再一章一章整理制作**：
   - 一次性粘贴或上传整篇几万字的模组Log，点 **分章**，AI自动在两三万字左右的剧情节点插入 `=== 第1章：标题 ===` 分隔符切成多章，并提取全模组出场人物名与环境场所。
   - 之后一章一章点 **整理**：**PC和NPC对话框只保留第一人称亲口说的话；其余所有动作和环境描写全部归入KP第三人称旁白，且绝不乱改原文语句，只把第一人称「我」换成角色名**；同时将所有对话翻译成日语供MiniMax配音。
3. **AI整理剧本时插入「歌名 + 歌手」，系统自动连JD音乐台 / 网易云 / QQ音乐按权重排序选第一首播放**：
   - AI在整理剧本时，会根据当前剧情氛围或Log里原本写的BGM提示，在对应台词行插入具体的 **歌名** 与 **歌手名**。
   - **不是让AI瞎猜链接，而是由系统自动去音乐台搜索**：系统内置多音源搜索引擎，自动连接 **JD音乐台、网易云音乐、QQ音乐** 搜索接口，拿到搜索结果后，自动按 **歌名匹配度 + 歌手匹配度 + 原版音源可用性** 进行权重打分排序，自动选中排名第一的歌曲解析出真实音频流并开始播放！
4. **清爽的「角色」分类档案柜 + 支持跨模组通用角色**：
   - 彻底删掉世界书、旧版深层秘密、思维链、小人餐桌等没用的模块。
   - 角色页按 **所属模组档案 / 通用常驻角色** 以及 **主角PC / 配角NPC / 旁白KP** 分类排布，找人一目了然。
5. **每个按钮下方都写好大白话备注 + 顶部傻瓜式教程 + 全部文字随时可手改**：
   - 界面上每个按钮下方都有一行清楚的大白话说明它干什么用；分章原文、人物名字、台词、旁白、日语配音、配乐歌名全部可以直接点框修改。

## 1. 智能音乐台搜索与权重排序播放机制

为了让你彻底省心，系统在后台与前端实现了完整的 **音乐台搜索与权重排序引擎**：

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. AI整理剧本时，在氛围转换行标注：【歌名】+【歌手/作曲】              │
│    或者识别跑团Log里KP原本写的 BGM 歌名                                │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 2. 系统自动并发检索：JD音乐台接口 / 网易云音乐 / QQ音乐                │
│    对返回的候选歌曲列表进行【权重打分排序】：                          │
│    ├─ 歌名完全一致：+60分  │ 歌名包含关键词：+30分                     │
│    ├─ 歌手/作者匹配：+35分 │ 排除翻唱/伴奏/Live杂音版：+15分           │
│    └─ 选出【权重总分第 1 名】的歌曲，自动获取可播放音频直链并缓存      │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 3. 剧场播放到该行时自动平滑切歌，且在角色日语配音说话时自动压低背景音  │
│    在【音乐】页和剧本行里也可以随时输入歌名歌手手动测试或换歌          │
└────────────────────────────────────────────────────────────────────────┘
```
