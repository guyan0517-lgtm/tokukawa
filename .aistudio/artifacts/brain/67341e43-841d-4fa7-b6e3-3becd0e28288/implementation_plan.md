# 视觉小说舞台1至3人动态槽位锁定与日系纯音乐渐入渐出自动播放方案

## 一、 方案目标与整体设计

1. **视觉小说舞台 1人 / 2人 / 3人 动态自适应槽位锁定**
   - 完全由系统算法自动完成，不消耗任何AI额度。
   - **单人场景**：当一段剧情只有1名角色说话或独白时，该角色在舞台正中央自然站立。
   - **双人场景**：当一段对话有2名角色互动时，系统自动预读接下来几句的对话搭档，在第一人开口时两人直接一左一右同台站好。对话过程中两人位置绝对锁定，轮到谁说话谁就高亮微抬、另一人微暗倾听，绝不左右互换位置。
   - **三人场景**：当一段剧情有3名角色同场交流时，系统自动切换为左、中、右三槽位固定站位，3个人在对话过程中各自固定在左、中、右位置，谁说话谁亮起，完全不会乱跳换位。
   - **人数自然增减与换人**：
     - 从1人独白加入第2人、第3人时，已有角色保持原槽位，新角色自然入驻空闲槽位。
     - 当某名角色超过一段台词未再发言且后续也不再参与当前对话时，系统自动将其退场，使舞台从3人平滑回落到2人或1人。
     - 当已有3人在场而第4名角色临时插话时，系统只原位替换掉当前最久未说话的那1个槽位，另外2名角色位置完全不动。

2. **日系动漫游戏纯音乐自动标记、即插即播与1秒平滑渐入渐出**
   - **章节整理自动配乐**：升级章节整理提示词与解析流程，要求AI在每章剧情起承转合处规划3至6处日系动漫、视觉小说或JRPG纯音乐与原声带伴奏作为 `BGM_REC` 音乐起点，并在紧张解除、压抑留白或场景切换处标记 `BGM_STOP` 音乐停止点。
   - **精准行号绑定**：将AI标记的音乐直接绑定在原始剧本行对象上，使行拆分或长句切分后音乐标记依然精准落在对应台词行，绝不偏移。
   - **剧本页新增「配乐」两字按钮**：在剧本控制台顶栏设置为两行四列共8个两字按钮，第一行为 `整理`、`配乐`、`差分`、`插图`，第二行为 `弹幕`、`错字`、`提示`、`播放`，并将分章页重复的 `差分` 按钮去重移除。点击 `配乐` 即可单独为当前章节重新规划日系纯音乐并自动绑定音源。
   - **舞台免下载直接播放与1秒渐入渐出**：
     - 整理或点击 `配乐` 时，系统自动调用音乐台接口检索并绑定可直接播放的日系纯音乐音频流，同时内置多首涵盖日常、悬疑、诡异、战斗、抒情、欢快氛围的日系纯音乐保底曲库。
     - 舞台播放到带有音乐标记的台词行时，音乐从0音量经过 **1秒平滑渐入** 升至设定音量；切换到另一首音乐时，旧音乐先经过 **1秒平滑渐出** 再将新音乐经过 **1秒平滑渐入**；遇到 `停止` 标记时，当前音乐经过 **1秒平滑渐出** 后自动停止。

## 二、 界面与代码增量修改清单

- **`/index.html`**
  - 剧本控制台顶栏按钮对齐为每行4个共两行两字按钮，新增 `配乐` 按钮并移除场景卡片上的重复 `差分` 按钮。
  - 新增 `fadeBgmVolumeTo` 1秒平滑音量渐入渐出控制器，升级 `previewReplayBgmTrack` 与 `stopReplayBgmPreview` 支持1秒渐入渐出及音源失效自动切换保底日系纯音乐。
  - 新增 `computeChapterStageSlots` 舞台1至3人动态槽位锁定算法，并升级 `renderTheaterCurrentLine` 支持1人居中、2人左右、3人左中右固定站位与同场表情保持。
  - 升级 `DEFAULT_REPLAY_SCRIPT_PROMPT` 与 `generateChapterScriptByIndex` 中的配乐行号追踪逻辑，新增 `aiMatchCurrentChapterBgm` 单章配乐重配函数。
- **`/style.css`**
  - 为 `.vn-tachie-layer` 补充 `data-actor-count="2"` 与 `data-actor-count="3"` 的自适应间距样式，确保三人同台立绘精致排布不裁切。
- **`/server.js`**
  - 在 `calcMusicMatchScore` 中为包含 `纯音乐`、`ost`、`soundtrack`、`bgm`、`instrumental`、`piano` 的日系原声纯音乐增加优先权重加分。
