# 模组地图直接展示与深度图片提取图库系统实现方案

## 一、需求核心目标

1. **模组地图直观呈现**：
   - 模组详情页中的地图标签页直接平铺展示所有场景与地点卡片，内嵌场景描述、探索状态与关联线索，无需跳转二级空页面，消除点击报错。

2. **文档嵌入图片完整提取**：
   - PDF：利用 pdf.js 逐页深度遍历全部 XObject 与 Inline 图像资源，提取真实嵌入位图；
   - DOCX：利用 JSZip 解压并提取 `word/media/` 目录下的所有嵌入高清图片；
   - 提取过程记录来源页码、原始分辨率（宽×高）、文件格式与所属模组，支持同一图片 xref 去重与单张提取容错兜底。

3. **AI 智能甄别与剧透分级**：
   - 过滤页眉页脚、无意义装饰线条与背景底纹；
   - 智能识别立绘、CG、地图与道具；
   - 判定剧透属性（如后期异化形态立绘、关键伤亡CG、密室停尸房地图标记为守秘剧透，初期常规立绘与公开村落地图标记为玩家可见）；
   - 玩家模式下，剧透图片统一替换为「图片已被肥鸭坐塌」黄鸭占位图，守秘人模式显示完整原图。

4. **严格图片显示尺寸规范**：
   - 聊天窗口、模组图库与正文插图中所有图片遵循等比自适应规则：宽度不超过容器最大显示范围，高度不超过视口高度的二分之一，禁止拉伸变形或撑破布局。

5. **图库管理与正文联动**：
   - 图库按模组展示，提供页码、尺寸、描述标签、点击大图查看、单张删除与一键清空；
   - 正文插图标记与图库精准联动。

## 二、开发执行规划

1. **pdf-parser.js / module-manager.js**：
   - 重构 PDF 页面资源扫描逻辑，逐页检索 `page.objs` 与 `page.commonObjs` 中的位图数据；
   - 集成 DOCX 媒体文件直接提取；
   - 注入 AI 图片过滤与剧透判定提示词。
2. **index.html & style.css**：
   - 优化模组地图视图为直观场景卡片流；
   - 增加全屏大图查看弹窗；
   - 注入全局图片容器约束 CSS 规则与肥鸭占位图样式。
3. **Dexie 数据库**：
   - 扩展 `moduleImages` 数据结构，存储 `pageNumber`、`width`、`height`、`format`、`isSensitive`、`description` 等元数据。
