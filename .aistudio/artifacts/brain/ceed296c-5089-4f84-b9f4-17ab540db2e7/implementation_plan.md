# 跑团模组切割与语音播报优化方案

本方案旨在解决跑团模组切割多卷全局能见度、语音播报模式与停顿机制、重构提示词统一以及校验环节基于预设提示词精准审查四大核心问题。

## 关键决策确认

- 决策一：语音多句台词停顿采用单次接口调用并在文本中智能插入停顿标记与省略号，保障单次合成且自然间隔。
- 决策二：语音播报模式切换初始为手动模式，点击切换为默认模式。
- 决策三：模组分卷切割时AI享有全篇模组全文、完整分析章节列表与目录的全局视野，仅限定输出目标分配章节。
- 决策四：环节二重新思考与环节三校验全面读取并绑定环节一分析提示词与环节二切割提示词，杜绝无依据臆想。

## 1. 概述与核心目标

- 模组切割全局视野：无论分为多少卷，每个分卷的切割AI均可获取模组完整原文、分析所得全部章节大纲与完整目录。各卷AI明晰前后文边界与散落补充信息，仅整理输出分配给本卷的具体章节。
- 语音交互与模式切换：去除三击台词语音播放时的外框高亮效果。在输入栏工具区新增双态模式切换按钮，两字文案切换。手动模式下由用户手动点击播放；默认模式下AI回复后自动扫描气泡提取书名号与直角引号中的台词逐一自动调用语音朗读，多句之间单次合成并带有平缓自然停顿。
- 第二环节重构提示词同步：修复第二环节中点击重构调用的提示词与第一环节预设分析提示词不一致的问题，确保严格继承当前激活的分析提示词及修改意见。
- 第三环节校验提示词对齐：校验环节全面引入第一环节分析提示词和第二环节切割提示词作为审查基准，结合章节大纲备注与原文片段进行对照质检，避免凭空制定严苛规则与挑刺臆想。

## 2. 用户界面与交互细节

- 视觉规范：完全复用已有界面风格与CSS变量，不增加多余边框，杜绝任何括号说明，功能按键名称严格保持两个字。
- 语音播报模式按键：在输入栏工具栏区域紧随相关操作位置布局。按钮名称默认为“手动”，点击切换为“默认”，状态即时持久化存储。
- 三击语音播放样式：移除播放中的外层光晕或外框阴影，保持原有气泡外貌自然播放。
- 模组页面切换持久状态：保持分卷选择器与分卷卡片数据在页面切换时不丢失，分析中按键状态根据实时分析状态自适应渲染，防止切换页面后文案异常重置。

## 3. 技术架构与执行逻辑

```
┌────────────────────────────────────────────────────────┐
│                   模组重构与切割工作流                 │
└────────────────────────────────────────────────────────┘
                           │
       ┌───────────────────┼───────────────────┐
       ▼                                       ▼
┌───────────────┐                       ┌───────────────┐
│ 环节一：分析  │                       │ 环节二：重构  │
│ 分析预设提示词│ ── 同步至重构与切割 ──▶│ 继承分析提示词│
│ 输出章节大纲  │                       │ 继承修改意见  │
└───────────────┘                       └───────────────┘
       │                                       │
       └───────────────────┬───────────────────┘
                           ▼
                ┌─────────────────────┐
                │    环节二：切割     │
                │ 全文输入 + 完整大纲 │
                │ 仅整理输出本卷章节  │
                └─────────────────────┘
                           │
                           ▼
                ┌─────────────────────┐
                │    环节三：校验     │
                │ 校验提示词包含:     │
                │ 1. 分析大纲提示词   │
                │ 2. 切割执行提示词   │
                │ 3. 对应章节大纲备注 │
                └─────────────────────┘
```

- 语音合成数据处理：在提取气泡中直角引号内容时，将多个引用片段以逗号及省略号连接，并辅以停顿标点，使Minimax语音合成在两句话之间自然形成停顿，且单次调用完成。
- 自动播放机制：AI生成完成触发回调，判断当前语音模式是否为默认模式。若为默认模式且已配置语音参数，则自动触发该消息台词朗读。
- 全模组全文与大纲传递：在分卷执行函数中，将原先仅截取单卷文本片段改为传入全模组全文，提示词中明确指出本卷只整理指定章节范围，同时附带前置分卷实际切割的接续起止锚点与备注说明。
- 校验提示词注入：在单章节校验与全局校验函数中，获取当前模组绑定的分析提示词与切割提示词，构建结构化审核要求，指导校验模型忠实于用户既定规则进行审查。
