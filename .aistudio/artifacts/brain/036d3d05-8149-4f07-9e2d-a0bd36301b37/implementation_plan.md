# 密友独立模块方案

## 目标与原则
建立独立的密友专属脚本文件，隔离所有密友逻辑与界面，不干扰现有其他对话功能。
密友功能仅保留好友交流与辅助外观，移除一切AI角色设定。

## 核心实现
1. 独立脚本隔离
新建 peer-manager.js 单独存放密友的创建、连接、码值管理与设置界面控制，实现代码彻底解耦。

2. 详情设置纯净化
在密友设置中自动过滤并隐藏对方人设卡片、我方人设卡片、模组、世界书、总结记忆、思维链、守密人等全部AI专属模块。
保留头像上传、头像生图、相框、图库、聊天背景、气泡主题、字体调节等外观美化功能。

3. 栏目归属与双向流转
在添加密友窗口中提供所属栏目下拉列表，支持存入任意分类，并支持点击复制密友码。
